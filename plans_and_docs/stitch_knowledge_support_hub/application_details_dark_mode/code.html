account_tree Architecture Summary

Finance Sync is built on a containerized Node.js runtime, orchestrating message queues via RabbitMQ. It utilizes Redis for caching frequently accessed ledger hashes and persists state in a partitioned PostgreSQL cluster.

  • Framework: Express.js / TypeScript
  • Messaging: RabbitMQ (Topic Exchange)
  • Data Store: PostgreSQL 14, Redis 7
